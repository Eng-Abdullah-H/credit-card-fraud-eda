# Credit Card Fraud Detection — EDA & Feature Engineering

## Project Overview

This project presents an end-to-end Exploratory Data Analysis (EDA) and feature engineering workflow on a highly imbalanced credit card transaction dataset.

The main objective is to understand transaction patterns, investigate fraudulent behavior, identify important relationships within the data, and prepare meaningful features for potential machine learning applications.

The project covers data cleaning, data quality assessment, statistical analysis, visualization, class imbalance analysis, and feature engineering.
## Dataset

The project uses a credit card transaction dataset containing anonymized transaction features and a binary target variable indicating whether a transaction is fraudulent.

Due to the large size of the raw and processed datasets, the CSV files are not included in this repository. The analysis notebook and generated HTML report are provided as the main project artifacts.

## Project Objectives

The main objectives of this project are to:

- Understand the structure and quality of the transaction data.
- Perform data cleaning and preprocessing.
- Analyze the distribution of legitimate and fraudulent transactions.
- Investigate relationships between transaction features and fraud occurrence.
- Identify patterns and potential risk indicators associated with fraudulent transactions.
- Engineer additional features that can improve downstream machine learning workflows.
- Produce a comprehensive EDA report documenting the analysis and findings.
